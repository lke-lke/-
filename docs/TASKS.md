## 6. 变更控制

- 用户确认后，SPEC-001 改为 done，DB-001 才能进入 in_progress。
- 产品字段、状态机、权限、统计口径或数据库契约发生变化时，先更新 PRD/ARCHITECTURE，并使受影响任务重新进入 pending。
- 不在聊天中用“已做”替代本文件状态，不创建第二份开发状态表。
- Git commit/push、部署和共享数据库执行属于独立外部动作，需用户明确授权。
